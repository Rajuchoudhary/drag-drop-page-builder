# Custom Drag & Drop Page Builder (Vanilla JavaScript)

🚀 A lightweight **Page Builder** built from scratch using only **Vanilla JavaScript, HTML, and CSS**.  
This project is part of a tutorial series where we build a complete **page builder UI** step by step without any frameworks or libraries.
